# Sprout

Sprout is a care tracker for plants and pets. This build is the shared Flutter frontend for Android and the web app. Screens use in-memory sample data so the app can run before the API is connected.

## Run

From the `frontend` folder:

```
flutter run -d chrome
```

Android, from the same folder:

```
flutter run
```

Sign in accepts any email and a password of at least 6 characters.
